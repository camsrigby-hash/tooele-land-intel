# Phase 18b-1 Current Zoning REST Inventory

This inventory records the official or city-linked ArcGIS REST current-zoning sources checked for the 13 active fallback jurisdictions from Phase 13b-5. Each exported GeoJSON feature uses `extraction_method: arcgis_rest` and `confidence: rest_api`; no PDF zoning extraction was attempted in this phase.

**Erda (`erda_ut`).** Checked the official Erda codes and maps page at <https://erda.gov/city-codes-and-maps/>, whose zoning-map link opens the Tooele County GIS ArcGIS web app. A current-zoning polygon REST layer was found at <https://tcgisws.tooeleco.gov/server/rest/services/Zoning/MapServer/1>; the layer name is `Zoning_Erda`, and it exported 63 features to `erda_ut_zoning.geojson`. No major extraction issue was observed.

**Tooele City (`tooele_ut`).** Checked the provided official ArcGIS web app item `ea1fc0fb757a454cae04dd1c36403c60` and inspected its backing services. A current-zoning polygon FeatureServer layer was found at <https://services3.arcgis.com/3PP5uLqByhZNekjG/arcgis/rest/services/Tooele_City__Land_Use___Zoning_WFL1/FeatureServer/2>; the layer name is `Zoning`, and it exported 112 features to `tooele_ut_zoning.geojson`. No major extraction issue was observed.

**Saratoga Springs (`saratoga_springs_ut`).** Checked the official Saratoga Springs Mapping/GIS path and its ArcGIS services; the city server path <https://gis.saratogaspringscity.com/arcgisweb/rest/services/Planning/Zoning/MapServer/0> was confirmed but layer 0 is a `PUD Overlay`, not the base current-zoning district layer. A base current-zoning polygon layer was found at <https://services.arcgis.com/M7jfYoTaLM0yE75d/arcgis/rest/services/Zoning_Districts_for_City_of_Saratoga_Springs/FeatureServer/0>; the layer name is `Zoning_Districts_for_City_of_Saratoga_Springs`, and it exported 884 features to `saratoga_springs_ut_zoning.geojson`. The issue is that the first city-hosted zoning MapServer layer encountered was an overlay, so the hosted zoning-district feature layer was used for the export.

**Eagle Mountain (`eagle_mountain_ut`).** Checked the official Eagle Mountain engineering/mapping source and ArcGIS services. A current-zoning polygon FeatureServer layer was found at <https://services1.arcgis.com/OZXOaoaD8hmdOtqR/arcgis/rest/services/General_Zoning_view/FeatureServer/0>; the layer name is `General_Landuse`, and it exported 1,392 geometry-bearing features to `eagle_mountain_ut_zoning.geojson`. The city also publishes `EMC_Zoning_View` at <https://services1.arcgis.com/OZXOaoaD8hmdOtqR/arcgis/rest/services/EMC_Zoning_View/FeatureServer/0>, but that layer appears parcel-level and much larger, so `General_Zoning_view` was selected as the zoning-polygon layer to avoid parcel duplication.

**South Jordan (`south_jordan_ut`).** Checked the official South Jordan GIS REST catalog at <https://gis.sjc.utah.gov/sjcmaps/rest/services> and related city GIS services. A current-zoning polygon MapServer layer was found at <https://gis2.southjordanutah.gov/server/rest/services/Development/Zoning/MapServer/0>; the layer name is `Zoning`, and it exported 423 features to `south_jordan_ut_zoning.geojson`. The future-land-use layer was intentionally not used for this phase.

**Herriman (`herriman_ut`).** Checked the official Herriman GIS path and its ArcGIS service references. A current-zoning polygon FeatureServer layer was found at <https://services2.arcgis.com/XBmqwOHlPh25M7aJ/arcgis/rest/services/HerrimanCityZoning/FeatureServer/0>; the layer name is `Zoning`, and it exported 262 features to `herriman_ut_zoning.geojson`. A second service, `Zoning_and_Subdivision`, contains a similar zoning layer, but the `HerrimanCityZoning` service was used as the direct city zoning source.

**Bluffdale (`bluffdale_ut`).** Checked the official Bluffdale planning/maps path and the ArcGIS web map item `7e0ac91dd8b74b2e8f5338f074636dbd`. A current-zoning polygon FeatureServer layer was found at <https://services3.arcgis.com/ojBMkFlpg5ujUNtB/arcgis/rest/services/Zoning/FeatureServer/0>; the layer name is `Zoning Polygons`, and it exported 89 features to `bluffdale_ut_zoning.geojson`. The same service also includes a `Neighborhoods and Developments` layer, but that was not used because it is not the base zoning district polygon layer.

**Draper (`draper_ut`).** Checked the official Draper GIS REST services at <https://gis.hlplanning.com/server/rest/services> and associated public FeatureServer references. A current-zoning polygon FeatureServer layer was found at <https://services2.arcgis.com/nAPVXppTJAHM40Se/arcgis/rest/services/Zoning_Public/FeatureServer/5>; the layer name is `Zoning`, and it exported 139 features to `draper_ut_zoning.geojson`. No major extraction issue was observed.

**Vineyard (`vineyard_ut`).** Checked the official Vineyard planning page and Vineyard City Public GIS Maps, then inspected ArcGIS item `16f0055b4f9849d5a66083d547f6c381`. A current-zoning polygon FeatureServer layer was found at <https://services.arcgis.com/QdlehUncXjEmQYtI/arcgis/rest/services/Zoning_-_Public_View/FeatureServer/8>; the layer name is `VNY_PLPZ_Zoning`, and it exported 51 features to `vineyard_ut_zoning.geojson`. An earlier similarly named service under a different ArcGIS organization did not expose the expected layer; the official item URL above was used.

**Lehi (`lehi_ut`).** Checked Lehi current-zoning ArcGIS candidates and selected the city zoning FeatureServer layer at <https://services9.arcgis.com/KAS2Ol4X7Ca0Dta5/arcgis/rest/services/Lehi_City_Zoning/FeatureServer/0>. The layer name is `Lehi_Zoning_CopyFeatures`, and it exported 514 features to `lehi_ut_zoning.geojson`. No major extraction issue was observed.

**American Fork (`american_fork_ut`).** Checked American Fork zoning ArcGIS services and found a current-zoning polygon MapServer layer at <https://maps.afcity.org/arcgis/rest/services/Planning/Zoning2/MapServer/0>. The layer name is `Zoning`, and it exported 208 features to `american_fork_ut_zoning.geojson`. The server presented an expired TLS certificate during this run, so REST requests were made with certificate verification disabled for extraction only; the REST layer itself responded successfully.

**Spanish Fork (`spanish_fork_ut`).** Checked Spanish Fork current-zoning ArcGIS candidates and selected the public zoning FeatureServer layer at <https://services.arcgis.com/FvF9MZKp3JWPrSkg/arcgis/rest/services/SF_Zoning/FeatureServer/0>. The layer name is `SF_Zoning`, and it exported 203 features to `spanish_fork_ut_zoning.geojson`. No major extraction issue was observed.

**Grantsville (`grantsville_ut`).** Checked Grantsville current-zoning ArcGIS candidates, including the city public GIS service and a hosted `Grantsville_General_Plan_Land_Use` layer labeled `Existing Zoning 2015 (Approximate)`. A current municipal zoning polygon REST layer was found in the Tooele County zoning service at <https://tcgisws.tooeleco.gov/server/rest/services/Zoning/MapServer/7>; the layer name is `Zoning_Grantsville`, and it exported 19 features to `grantsville_ut_zoning.geojson`. The issue is that another available Grantsville layer was explicitly approximate and dated 2015, so it was not used for current-zoning export.

## PDF-path note

No active jurisdiction in this 13-city batch was moved to the PDF-only path for Phase 18b-1. Several cities still have zoning ordinances or development-standard links in their source attributes, but each city had a usable current-zoning ArcGIS REST polygon layer for this task.
